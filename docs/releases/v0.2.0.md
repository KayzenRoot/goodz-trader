# v0.2.0 — Hardening, Ops & Research (pre-release)

This is still a **pre-release**. Live trading has **not** been validated with real funds; keep
`LIVE_TRADING_ENABLED=false` until issue #17 is completed with a tiny live order and a recorded
reconciliation.

## Highlights

- **Live hardening**: private MEXC WebSocket, reconnect reconciliation, idempotent submit,
  bounded maker requotes, partial-fill handling, single taker fallback, halt on ambiguous submit.
- **Reliable notifications**: non-blocking bounded queue, retry/backoff/timeout, dedupe,
  Telegram/webhook test endpoint, close-failure/stale-feed/daily alerts.
- **Dashboard Pro**: alert center, trade candle replay, paper vs live comparison, 390px mobile
  fixes, accessible labels/charts, reduced motion, 10 Playwright E2E checks.
- **Deploy & ops**: Docker image/compose validated, non-root, healthcheck/readiness,
  WAL-safe backup, verified restore drill, retention, Prometheus metrics/rules, graceful SIGTERM.
- **Research**: deterministic snapshot replay through the same strategy/risk/exit logic with
  fees, slippage, latency, funding, liquidation, walk-forward and versioned reports.
- **Ledger**: additive micro-USDT columns, dual-write, exact daily/realized sums and a
  reconciliation CLI that reports historical deltas without rewriting them.

## Verification

- 120 API + 66 core + 30 MEXC + 17 web unit/integration tests.
- 10 Playwright E2E (smoke, mobile, accessibility).
- CI: Quality Gate, CodeQL, E2E, Semgrep, Gitleaks, SonarCloud, Codecov, Socket, Scorecard.
- Docker: image built, compose healthy, non-root, backup/restore drill, clean `Exited (0)`.
- Backup drill: 209 trades / 505 equity points restored with identical counts.
- Ledger reconciliation: 209 trades, 0 mismatches, exact closed net `243.117459` USDT.

## Known limitations

- **Live execution is unvalidated** (#17): credentials, one-contract order, fee/average-price
  reconciliation and live maker semantics remain beta.
- Docker image still carries dev dependencies (~884 MB uncompressed); production-only pruning
  is future work.
- No off-host backup shipping; operator must schedule/copy verified backups.
- No automatic market-data recorder; backtests need recorded JSONL snapshots.
- SQLite REAL fields remain for display/CSV compatibility; some analytics still aggregate REAL
  rather than the new micro columns.
- Funding/liquidation in replay are approximations.
