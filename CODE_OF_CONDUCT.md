# Code of Conduct

## Our commitment

We want participation in Goodz Trader to be harassment-free for everyone, regardless of
experience, identity, background or trading skill. Be direct about code and kind about
people.

## Expected behavior

- Critique the change, not the person.
- Assume good intent; ask for context before escalating.
- Respect risk warnings and never pressure someone to trade live or increase size.
- Do not post API keys, account balances, personal data or exploit details publicly.
- Accept maintainer decisions about scope and safety.

## Unacceptable behavior

- Harassment, discrimination, threats, sexualized content or doxxing.
- Publishing another person's credentials, positions or private messages.
- Encouraging reckless leveraged trading or promising returns.
- Deliberately bypassing safety gates, secret handling or branch protection.
- Spam, market manipulation or illegal activity.

## Enforcement

Report concerns privately via GitHub's report/abuse tools or the maintainer's GitHub profile.
Maintainers may warn, remove content, lock threads or ban accounts. Security reports follow
[SECURITY.md](SECURITY.md), not public issues.

## Scope

This applies in the repository, issues, PRs, discussions, chat and any space representing the
project.
